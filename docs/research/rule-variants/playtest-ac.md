# A / C 比較試遊の手引き（2026-11-17）

第二次研究（[README.md](README.md)）の結果を受けて、A と C を実際に遊び比べられるようにした。
D は対局の長さがまったく違う別のゲームとして、比較には混ぜずに遊べるようにしてある。

| | A 現行ルール | C 王手救済 | D 王手で罠消滅 |
| --- | --- | --- | --- |
| 目指すもの | 危険な選択肢から生き残る心理戦 | 相手の選択肢を一つに絞る戦略ゲーム | 罠は中盤の駆け引き、終盤は寄せ合い |
| 違い | 王手の受けが罠にかかったら、そのまま王を取られる | 王手の受けが罠にかかったら、罠を見てから 1 回だけ指し直せる（罠のマスには指せない） | 王手をかけた手番に置いた罠は消える |
| 自動対戦での手数（中央値） | 26 | 47 | 116 |

## 揃えたもの

- 盤面・駒・効果音・罠の演出・ログ・終局後の罠履歴レビューは、3 つとも同じ。
- Bot も同じ。Hard は読み合いエンジンにルールを渡して読む（研究で使ったものと同じ）。Easy / Normal はルールを区別しない（3 つとも同じ弱さ）。C の指し直しでは、罠のマスを外して指し直す。
- 違うのは「王手の時の罠の扱い」だけ。盤の上の帯と、ヘッダーのバッジ（A=赤 / C=水色 / D=藍）で、今どのルールかが常に見える。

## 遊び方

1. スタート画面の「罠ルール」で A か C を選ぶ（対局中は右上の「⋯」からも変えられる。対局中なら確認が出る）。
2. 対局が終わると「決着の振り返り」が出る。
   - どう決着したか（受けに罠 / 一本道の受けを罠で封鎖 / 指し直しても受からず / 受けを外した / 詰み / 投了）
   - 王手の受けがどこに何か所あったか、罠がどこだったか
   - 「この負け（勝ち）、納得できた？」を 1〜5 で選ぶ（任意）
   - 「もう一局（同じルール）」「もう一方のルールで比べる」「メニューへ」のどれかを押す
3. 押したボタンも記録される。**「同じルールでもう一局」を選んだ割合が、そのルールの「もう一局！」度**。

## 試遊ログ

- スタート画面の「試遊ログ」に、ルールごとの 局数 / 勝-負 / 手数 / 負けの納得感 / もう一局率 / 多い決着 が出る。
- 記録はこの端末のブラウザ（localStorage）にだけ残る。サーバーには送らない。
- 「JSON で書き出す」でファイルに保存できる。複数人の試遊を集める時はこれを送ってもらう。
- 1 局の記録: ルール、モード、Bot の強さ、Casual/Strict、勝敗、決着の形、手数、最後の王手の受けの数、罠の命中数、C の指し直し回数、D の消えた罠の数、納得感、次に押したボタン、メモ。
- オンライン対戦は現行ルール（A）のみで、試遊ログにも記録しない。

## 見てほしいこと

- 負けた時、「読み負けた」と感じるか「くじに外れた」と感じるか（納得感の 1〜5）。
- C で「受けを 1 つに絞ってから罠で塞ぐ」攻め方を、自分から狙うようになるか。
- C の指し直しが「助かった」になるか「長引いただけ」になるか。
- A と C を交互に遊んだ時、どちらで「もう一局」を押したくなるか。
- D は別枠で、長い対局が楽しいか・だれるか。

## 自動対戦との対応

試遊ログの「決着の形」は、研究の分類（`scripts/research/variant-rules.mjs` の `classifyEnding`）と同じ考え方で数えている。
対応関係は `tests/static/ending-review-playtest.mjs` で確かめている（研究側の hopeless は、アプリでは「受けを外した」「王が素抜け」のどちらかになる）。
