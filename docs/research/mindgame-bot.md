# 読み合いエンジン 研究メモ（2026-11-17）

Hard Bot を「罠を疑い、欲張り、ときどきブラフを張る相手」にするための調査・実装・自動対戦の記録。
採用するかどうかは試遊で判断してください（このメモは自動対戦の数字だけに基づく。人間の試遊はまだしていない）。

## 1. このゲームの読み合いの正体

1 ターンは「罠を置く側が 1 マス選ぶ」「指す側が着地点を選ぶ」の同時手番ゲームになっている。
着地点 i に進めた時の価値を v_i、罠にかかった時（＝パス）の価値を p とすると、均衡は閉じた式で解ける。

- 罠側: おいしい着地点ほど高確率で罠を置く。 `q_i = (v_i - u) / (v_i - p)`
- 指す側: おいしい手ほど**低い**確率で指す。 `x_i ∝ 1 / (v_i - p)`
- u はその局面の「読み合い込みの形勢」。

ここから出てくる、このゲーム固有の性質:

| 性質 | 中身 |
| --- | --- |
| 単独の取りは止まる | 取れる駒が 1 つだけなら、罠で 1 手は確実に止められる |
| 両取りが本当の脅威 | 同じくらいおいしい手が 2 つあると、罠は半分しか止められない |
| 罠は 1 手しか守れない | 同じマスに連続で置けないので、止められた手は次のターン必ず通る |
| 公開された罠マスは次は安全 | 直前に公開・発動した相手の罠マスは、今回は絶対に罠ではない |
| 王手は「1/受けの数」の即死 | 受けが k 通りなら、罠側は約 1/k でその受けを潰して勝つ。受け 1 つは詰み |

## 2. 実装したもの

`src/game/mindgame.ts`（入力は `GameView` だけ）

- 罠ゲームの均衡ソルバー（`solveTrapGame`）
- 罠を織り込んだ 2 手読み。通常の minimax の「最大値」を「罠ゲームの価値」に置き換えた探索
- 罠と指し手を 1 ターン分まとめて計画（`planMindGameTurn`）。罠は「自分の手が通った局面」と「自分の手が罠で失敗した局面」の両方を、失敗確率で重み付けして選ぶ
- 「直前に公開された罠マスは安全」の推理
- 失うものが小さい時は、均衡から外れて欲張る（`GAMBLE_SHARPNESS`）
- 公開履歴から相手の癖を読み、配分を最大 4 倍まで傾ける（直近 24 手）

Hard だけをこのエンジンに切り替えた。Easy / Normal は変更なし。

## 4. 分かったこと

1. **旧 Hard は Normal より強くなかった。** 決着した局の勝率は 41.7% で、半分以上（530/1000）が 300 手引き分け。難易度の階段が上で崩れていた。
2. **新 Hard は「罠を読む」部分で差がついている。** 罠にかかる率が相手の 1/3〜1/4。
3. **強い者同士の対局は、ほぼ全て王手の読み合いで決まる。** 新 Hard 同士 1000 局のうち 963 局は「負けた側の最後の手が罠で失敗 → 次に王を取られる」で終わる。手数の中央値は 25 手（Strict で 31 手）。
4. **読みの深さより罠の読みの方が効く。** 深さを 2 → 3 にしても有意に強くならない。
5. **「葛藤」は 3 手に 1 回起きている。** 新 Hard 同士で、有力な手が 2 つ以上あり成功と失敗の差が大きいターンは 30.5%（Strict 42.1%）。Strict の方が読み合いが濃く、形勢の入れ替わりも多い（1 局あたり 1.71 回、Casual は 1.05 回）。

## 5. 試遊で見てほしいこと

- 新 Hard は Easy / Normal にほぼ全勝する強さ。人間にとって「理不尽」か「読み負けた」と感じるか。
- 王手をかけられて受けを罠で潰される負け方が、納得できるか、運任せに感じるか。
- 対局が短い（強い者同士で 25 手前後）。物足りないか、テンポが良いか。
- Bot がたまに取れる駒を取らない／取りに来て罠にかかるのが、人間らしく見えるか。

## 6. 未着手・次の候補

- 人間の試遊評価（上の 4 点）。
- 3 の「王手ルーレット」が単調に感じられた場合のルール実験（例: 王の移動には罠が効かない）。自動対戦の仕組みはそのまま使える。
- Normal を「読み合いエンジンの弱め版」にして難易度の階段を作り直す。
- デバッグパネル（`?debugBot`）は旧 Hard の評価を表示したまま。新エンジンの候補手・罠確率を出すようにする。
- `GameView.log` が相手の `pitfallSet`（まだ有効な罠の位置）をそのまま含んでいる。Bot は読まないが、オンライン対戦のクライアントには届く。
